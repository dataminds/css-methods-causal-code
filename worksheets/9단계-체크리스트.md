
# 부록 D · 9단계 체크리스트

> 논문을 쓸 때 들고 가는 한 장이다. 각 단계에서 스스로 답해야 하는 물음과, 그 답의 산출물(논문 어디에 어떤 형태로 남는지). 자율 시나리오(S4·S5)와 기말 과제의 제출 양식이기도 하다. 칸마다 한두 문장이면 된다.

| 단계 | 스스로 묻기 | 산출물 (논문의 어디에) |
|---|---|---|
| ① 연구질문·가설 | 기술인가 인과인가? 가설 문장에 변수·방향·비교가 다 있는가? 자료 보기 전에 적었는가? | 가설 목록 (서론 끝 ; 사전등록) |
| ② 설계·식별 | 인과를 어디서 사 오나(무작위·통제·시간·단절)? 그 설계가 사는 가정은? 이 효과를 잡을 검정력은? 사람이 대상이면 심의 승인을 받았나? | 설계 진술 + 검정력 계산서 + 심의 승인 기관·번호와 동의 절차 (방법) |
| ③ 자료·정제 | 행 = 무슨 단위? 제외 기준을 미리 정했나? 제외 후 n은? 결측을 어떻게 처리했나(목록별·변수별·대치)? (종단이면) 이탈은 무작위인가? | 표본 흐름(원자료→분석 표본) + 균형·이탈 표 (방법·결과 앞) |
| ④ 측정 | 이 변수가 그 개념인가(조작적 정의)? 척도를 어디서 가져왔고 번안·수정했나? 신뢰도는(α ; 텍스트면 코더 간)? 실패한 요소는 어떻게 처리했나? | 척도 서술(출처·번안·허가·수정) + 신뢰도 보고 (방법) |
| ⑤ 기술·시각화 | 분포를 봤는가(치우침·극단값)? 표 1을 만들었는가? | 표 1 + 필요시 분포 그림 (결과 앞) |
| ⑥ 가정 점검 | 이 분석이 성립하는 조건은? 지금 성립하나(균형·조작 점검·통제의 논거·잔차)? 통제 목록에 이유를 달았나? | 점검 결과 문장 + 통제 논거 (방법·결과) |
| ⑦ 주 분석 | 가설 순서대로 했나? 계획한 분석 그대로인가(바꿨다면 표지)? | 핵심 수치 네 종 세트(M·SD/검정/효과크기/CI) (결과) |
| ⑧ 강건성 | 다르게 해도 사는가(공변인·제외 기준·하위집단)? 위약·극단값 시험은? 안 나온 결과도 제자리에 있나? | 강건성 문단 또는 부표 (결과 뒤) |
| ⑨ 해석·보고 | 설계가 산 만큼만 말했나(인과어 점검)? 크기를 정직하게(형용사에 근거)? 한계는 실명·정량·해소 경로로? 재현 패키지(자료·코드·씨앗)는? | 결론 + 한계 절 + 공개 자료 링크 (논의) |
| ⊕ 검증 로그 | 분석마다 3종(독립 재계산·극단값·재실행)을 코드로 했는가? | 검증 로그 (부록 B 양식 ; 제출물 동봉) |

## 분석 순서 (자료를 만지는 차례)

위 표는 **논문의 뼈대**다. 그런데 실제로 자료를 만지는 차례는 그것과 완전히 같지 않다.

⭐⭐ **논문에 적히는 순서와 분석하는 순서는 다르다.** 1장이 「결과 절부터 거꾸로 읽기」를 가르쳤는데, 그 짝이 이것이다. **논문 순서대로 분석하지 않는다.** 표 1이 논문 앞쪽에 있다고 표 1을 먼저 만드는 것이 아니다.

일곱 국면으로 나눈다. 가운데 그어진 **잠금선**이 이 표의 요지다.

| 국면 | 무엇을 하나 | 산출물 | 되돌아가도 되나 |
|---|---|---|---|
| **0** 자료를 열기 전 | 가설 목록에 순서를 매긴다(주·이차·탐색) · **주 분석 하나를 지정** · 제외 기준 · **결측 처리 방식** · 통제 목록을 화살표로 · 검정력 | 분석 계획서(사전등록이면 여기서) | 자료를 안 봤으니 자유 |
| **1** 열되 결과는 안 본다 | 한 행이 무엇인가 · 행·열 수 · 결측 **패턴** · 제외 기준 적용 · 0에서 정한 결측 처리 적용 | **표본 흐름**(원자료 → 제외 → 분석 표본) | ⭐ 0으로 되돌아갈 수 있다. 단 기록한다 |
| **2** 변수를 만든다 | 역채점 되돌리기 · 문항 평균 · 신뢰도 · (실험이면) 조작 점검 | 척도 서술 + 신뢰도 | ⭐ 알파가 낮으면 1로 돌아간다 |
| **3** 한 변수씩 본다 | 분포 그림 · 치우침 · 천장과 바닥 · (실험이면) **공변인만으로** 기저 균형표 | 표 1의 앞부분 + 분포 그림 | ⭐ 가능. 여기까지가 마지막 기회다 |
| 🔒 | **잠금선** | | |
| **4** 관계를 본다 | 계획한 **주 분석 하나** → 가정 점검(잔차·흩어짐) → 효과크기와 구간 | 네 종 세트 | ⛔ **여기서부터 되돌아가면 갈림길이다** |
| **5** 흔들어 본다 | 0에서 미리 정한 갈래 두셋 · 검증 3종(독립 재계산·극단값·재실행) | 강건성 문단 + 검증 로그 | ⛔ 새 갈래를 여기서 만들면 탐색이다 |
| **6** 쓴다 | 이차 가설 · 탐색(표지를 달고) · 표와 그림 · 결과 절 · 한계 절 · 재현 패키지 | 논문 | |

### 잠금선이 정확히 어디인가

⭐ **결과변수를 집단·조건별로 쪼개 보는 순간**이다.

그 전까지는 자료를 아무리 봐도 방향을 모른다. 결과변수의 전체 분포를 봐도, 공변인을 집단별로 봐도 모른다. 그런데 **결과변수를 집단별로 쪼개는 순간 답을 알게 되고**, 그 뒤의 모든 결정이 그 앎에 오염된다.

⚠ **그래서 표 1을 만드는 시점을 조심한다.** 많은 논문의 표 1에 결과변수가 집단별로 들어 있는데, 그것은 **보고 순서**이지 분석 순서가 아니다. 분석에서는 그 칸을 국면 4에서 채운다.

### 되돌아가기는 금지가 아니라 기록 대상이다

실제 분석은 선형이 아니다. 국면 2에서 알파가 무너지면 1로 돌아가 문항을 다시 본다. 그것은 정상이고 좋은 연구다.

⛔ **문제는 되돌아간 사실을 논문에 안 쓰는 것이다.** 그리고 **잠금선을 넘은 뒤의 되돌아가기**다. 결과를 본 뒤에 제외 기준을 고치거나 척도를 다시 만들면, 아무리 정당한 이유가 있어도 **그 정당함을 독자가 확인할 길이 없다.**

⭐ 처방은 하나다. **잠금선 뒤에 되돌아갔으면 그 사실과 이유를 쓴다.** 「주의 점검 기준을 결과 확인 후 재검토했고, 두 기준의 결과를 모두 보고한다」는 문장이 있는 논문과 없는 논문은 다르다.

### AI를 어디에 쓰나

| 국면 | AI에게 시켜도 되는 것 | 사람이 쥐는 것 |
|---|---|---|
| 0 | 선행 연구에서 효과크기 찾기 · 검정력 계산 코드 | **가설의 순서와 주 분석 지정** |
| 1~3 | 불러오기 · 요약 · 그림 코드 | **제외 기준과 척도의 판단** |
| 4 | 분석 코드 · 출력 | **가정 위반을 어떻게 처분할지** |
| 5 | 갈래마다 돌리기 | **어느 갈래를 미리 정했는지** |
| 6 | 표·그림 조판 · 문장 다듬기 | **말할 수 있는 것과 없는 것** |

⭐ 규칙이 하나로 모인다. **AI는 잠금선 양쪽에서 코드를 짜 주지만, 잠금선이 어디인지는 사람만 안다.**

## 채점 기준 (제출물 판정)

제출 양식이 곧 채점 기준은 아니다. 위 표가 「무엇을 내는가」라면 아래는 **「무엇이 잘한 것인가」**다. 기말 과제와 자율 시나리오(S4·S5)의 판정에 쓰고, **제출 전에 스스로 채점하는 데 먼저 쓴다.**

| 단계 | 미흡 | 우수 |
|---|---|---|
| ① 연구질문·가설 | 가설에 방향이 없다 ; 자료를 본 뒤에 주 가설을 골랐다 | 가설마다 결과 변수·방향·비교 대상이 문장 안에 있고, 주·이차 서열이 자료 이전에 정해졌다 |
| ② 설계·식별 | 설계 이름만 적었다 | 그 설계가 사는 가정을 한 문장으로 쓰고, 검정력을 계산해 못 잡을 때의 각오까지 밝혔다 |
| ③ 자료·정제 | 제외 후 n만 적었다 | 제외 전·후 인원과 비율을 적고, 제외가 결론을 바꾸는지 확인했다. 종단이면 이탈 분석까지 |
| ④ 측정 | 전체 α만 보고했다 | 요소별 신뢰도를 싣고, 낮은 요소를 어떻게 처리했는지와 그 이유를 밝혔다 |
| ⑤ 기술·시각화 | 표 1의 M·SD 만 실었다 | 분포를 보고 나서 표를 만들었고, 천장·바닥을 비율로 확인했다 |
| ⑥ 가정 점검 | 통제 목록만 있다 | 목록마다 이유가 붙어 있고, 넣지 않은 변수(충돌 등)의 이유도 함께 있다 |
| ⑦ 주 분석 | *p*만 보고했다 | 네 종 세트(M·SD / 검정 / 효과크기 / 신뢰구간)를 갖췄고, 계획한 순서대로 보고했다 |
| ⑧ 강건성 | 흔든 갈래 중 좋은 것만 실었다 | 흔들 갈래를 미리 정하고 전부 보고했다. 결론이 바뀌지 않았다면 그 사실도 보고했다 |
| ⑨ 해석·보고 | 한계가 형식적 겸사다 | 설계가 산 만큼만 말했고, 한계를 실명·정량·해소 경로로 적었다 |
| ⊕ 검증 로그 | 「확인했다」로만 적었다 | 세 검사를 코드로 하고 결과를 수로 적었다. 못 한 검사는 안 했다고 밝혔다 |

⭐ **이 표를 제출 전에 스스로 한 번 채점하라.** 그것이 이 책이 내내 가르친 자기 검증의 마지막 적용이다. 남이 채점하기 전에 자기가 채점해 보는 것과 그러지 않는 것의 차이는, 코드를 돌려 보고 결과를 받는 것과 지어내는 것의 차이와 같다.

⚠ 「보통」 칸은 일부러 비워 놓았다. 미흡과 우수 사이는 연구마다 다르고, **가운데를 미리 규정하면 그 규정이 목표가 된다.** 두 끝만 알면 어디로 갈지는 정해진다.

## 칸마다 흔한 실패

체크리스트는 빈칸을 채우는 것보다 **잘못 채우는 것**이 더 흔하다. 이 책이 각 칸에서 본 실패의 대표형이다.

| 단계 | 흔한 실패 | 어디서 봤나 |
|---|---|---|
| ① | 가설에 방향이 없다 ; 자료를 본 뒤에 주 가설을 골랐다 | S1 ① · 20장 |
| ② | 인과어를 쓸 계획인데 설계가 그 값을 안 냈다 ; 검정력을 안 재고 시작했다 ; 심의 승인과 동의 절차를 안 밝혔다 | 15장 · S2 · 19장 §19.1 |
| ③ | 제외 기준을 결과를 보고 정했다 ; 제외가 한쪽 집단에 몰렸다 ; 결측 처리 방식을 안 밝혔다(표마다 n이 다른데 설명이 없다) ; 평균 대치로 표본을 부풀렸다 | 3장 §3.3·§3.6 · S1 ③ |
| ④ | 전체 α만 보고했다(요소별로 무너진 곳이 있다) ; 낮은 문항을 자동으로 뺐다 ; 역채점을 되돌리지 않았다(알파는 거의 안 움직이고 문항-총점 상관만 음수다) ; 척도 출처·수정을 안 밝혔다 | 4장 §4.1·§4.2 · S6 ④ |
| ⑤ | 표 1의 M·SD만 보고 분포를 안 봤다 ; 천장·바닥을 안 셌다 | 5장 §5.1 |
| ⑥ | 통제 목록에 이유가 없다 ; 설명량이 안 오른다고 통제를 뺐다 | S3 ⑥ · 15장 |
| ⑦ | p만 보고했다 ; 유의하지 않은 것을 "효과 없음"으로 썼다 | 19장 §19.3 · S2 |
| ⑧ | 흔든 갈래 중 좋은 것만 실었다 ; 충돌 변수를 "혹시 몰라" 넣었다 | 20장 · S3 ⑧ |
| ⑨ | 한계가 형식적 겸사다 ; 크기의 형용사에 근거가 없다 | 19장 §19.5 |
| ⊕ | 검증을 손계산으로 했다 ; 못 한 검사를 안 적었다 | 부록 B |

⭐ 이 표를 체크리스트와 나란히 놓고 보면, 각 칸의 물음이 왜 그렇게 쓰였는지가 보인다. **물음은 실패에서 역산해 만든 것**이다.

## 쓰는 법

- **논문 시작 전**: ①②를 먼저 채운다(자료 보기 전 ; 20장). 이 두 칸이 비어 있으면 아직 분석을 시작할 때가 아니다.
- **분석 중**: ③~⑧을 순서대로. 건너뛴 칸이 곧 심사평이 된다.
- **공저자 회람 전**: 칸마다 한 문장씩 채운 이 표를 원고와 함께 보낸다. 공저자가 가장 빨리 도울 수 있는 것이 "②의 가정이 정말 서는가" 같은 물음이고, 그것은 원고 본문보다 이 표에서 먼저 보인다.
- **투고 전**: ⑨와 ⊕로 마감. 특히 "인과어 점검"이다. 결과·논의의 모든 동사를 훑어 설계가 지불하지 않은 인과어("높인다", "효과")를 걷어 낸다.

## 네 물음 낱장

> 아홉 단계가 **논문의 뼈대**이고 분석 순서가 **자료를 만지는 차례**라면, 네 물음은 **결과 앞에서의 판정 순서**다. 상관 하나를 만날 때마다 이 넉 장을 차례로 넘긴다. 원전 = 7장 §7.4.

| # | 물음 | 무엇이 답하나 | 못 답하면 |
|---|---|---|---|
| **1** | **관계가 있나** | 표본 요동과 견준다(12장) · 구간의 폭(13장) | "판정할 수 없었다"(⛔ "없었다"가 아니다) |
| **2** | **방향이 있나** | 시간 · 이론 · 설계. ⛔ 자료가 아니다(6장 §6.1) | 방향 없이 관계만 보고한다 |
| **3** | **인과인가** | 설계가 사 준 만큼(9장 §9.4). 통제는 잰 것까지만(15장) | 관계어로 쓰고 한계에 실명으로 남긴다 |
| **4** | **크기를 말할 수 있나** | 효과크기와 구간(13장) · 측정의 질(4장) | 크기의 형용사를 쓰지 않는다 |

⛔ **넷은 관문이 아니다.** 앞 물음에 못 답했다고 뒤를 묻지 못하는 것이 아니라, **답할 수 있는 강도가 정해질 뿐**이다. 1에서 유보해도 2·3·4를 물을 수 있고, 그때의 답은 "이 자료로는 여기까지"가 된다.

⭐ **쓰임 셋.**

1. **남의 논문을 읽을 때** = 넷을 차례로 대고, 저자가 어디까지 갔는지와 어디서 넘었는지를 본다(10장이 그 훈련이다).
2. **내 결과를 쓸 때** = 넷 중 채운 칸은 논의로, 빈 칸은 한계로 보낸다(19장 §19.5).
3. **분석을 계획할 때** = 넷째 칸까지 가고 싶으면 **설계 단계에서** 무엇을 사야 하는지 거꾸로 짚는다(9장).
