# 재현 검증 · 『사회과학 통계와 인과추론』

이 폴더는 책에 인쇄된 수치가 맞는지 **누구나 다시 확인할 수 있게** 만든 검증 도구다. 책의 수는 모두 이 저장소의 공개 자료(`data/journey_*.csv`, 씨앗 73으로 만든 모의 자료)와 코드에서 나온다. 검증은 서로 독립된 두 층으로 한다.

| 층 | 무엇을 보나 | 실행 |
|---|---|---|
| 1. 코드 출력 대조 | 책에 실린 코드 블록을 장마다 책 순서대로 실행해, 책에 적힌 출력과 **글자 그대로** 같은지 | `python doctest_book.py` |
| 2. 산문 수치 대조 | 책 문장 속의 수를 **파이썬과 R로 따로** 계산해, 두 값이 모두 책의 표기로 반올림되는지 | `python verify.py` |

두 층 모두 허용폭을 따로 두지 않는다. 산문 수치 대조는 계산값을 책의 자릿수로 한 번 반올림한 답이 책의 표기와 같아야 통과한다. 반올림은 두 엔진에 공통인 규칙 하나로 한다. 계산값을 유효숫자 12자리로 정리해 이진 저장 잡음을 걷고(2.67499999999999982 → 2.675), 십진 「반은 올림」으로 맞춘다(`verify.py` 의 `half_up`). 파이썬 `round()` · numpy · R `round()` 는 정확히 반인 값(0.125 · 5.135)에서 서로 다른 답을 내기 때문이다. 책이 「0.172」라고 썼으면 계산값이 0.1715 이상 0.1725 미만이어야 하고, 정확히 0.1715 이면 0.172 로 맞춘다.

## 공개판에 대해

공개 저장소의 이 폴더에는 계산 코드 · 책의 코드 블록 사본(`book_code/`) · 대조표가 있다. 대조표에서 책 문장 조각(`anchor` 열)은 뺐다. 그래서 공개판의 2층 검증은 「두 엔진의 계산값이 대조표의 인쇄 표기로 반올림되는가」를 본다. 그 인쇄 표기가 책에 실린 수와 같은지는 책을 가진 독자가 `id`(단위 · 절 · 내용의 줄임)와 `printed` 로 찾아 확인한다. 책 문장과의 대조(anchor)는 저자 쪽 원본 저장소에서 같은 검사기로 돈다.

## 준비

- 파이썬 3.11 이상 · `pip install -r requirements.txt`
- R 4.x (기본 R만 쓴다 ; 추가 패키지 없음). `Rscript` 가 경로에 있어야 한다.

## 대조표 (`claims/*.csv`)

책에 인쇄된 수 하나가 한 줄이다.

| 열 | 뜻 |
|---|---|
| `id` | 고유 이름 |
| `unit` | 책의 단위(ch05 · s2 · b1 …) |
| `anchor` | 그 수가 들어 있는 책 문장의 조각. **책에 글자 그대로 있어야 한다.** 책의 수를 고치면 이 조각이 사라져 검증이 실패한다. 그래서 책과 대조표가 언제나 함께 바뀐다 |
| `printed` | 책에 인쇄된 수 그대로(`.283` · `−0.01` · `22.2` · `366`) |
| `calc` | 계산 이름. `py/units/*.py` 와 `r/units/*.R` 이 같은 이름으로 따로 계산한다 |
| `kind` | `data` 배포 자료로 계산(두 엔진이 같은 값을 내야 한다) · `sim` 난수 모의시행(파이썬은 책 표기와 맞아야 하고, R은 자기 난수로 `mc_tol` 안에 들어야 한다) · `paper` 남의 논문이 보고한 값(출처를 `note` 에) · `fixed` 정의 · 설계로 정해진 수(척도 끝값 · 씨앗 · 모의시행에 심은 값 · 예시 숫자 ; 근거를 `note` 에) |
| `mc_tol` | `sim` 일 때 두 엔진 차이의 허용폭과 그 근거(몬테카를로 표준오차) |
| `note` | 출처 · 근거 |

### 왜 R 은 파이썬과 다른 난수를 쓰나

R과 numpy의 난수 생성기는 같은 씨앗에서도 다른 수열을 낸다. R이 numpy를 흉내 내면 독립 확인이 되지 않는다. 그래서 모의시행은 R이 **같은 설계를 자기 난수로 따로 돌리고**, 두 결과가 몬테카를로 오차 안에서 맞는지를 본다. 자료로 계산하는 수(`data`)는 두 엔진이 같은 값을 내야 한다(상대 차이 10⁻⁸ 이하).

### 남의 논문 수치

책이 인용한 논문의 수치(`paper`)는 원 논문 쪽 번호를 `note` 에 남긴다. 원 연구의 원자료는 재배포 허락이 없어 이 저장소에 싣지 않는다. 원자료로 다시 계산한 기록은 `note` 가 가리키는 문서에 있다.

## 대조표를 채우는 규칙

1. 책 단위의 **모든** 수를 분류한다. 아직 묶이지 않은 수 = `python verify.py --uncovered ch05`.
2. `anchor` 는 수를 포함하는 가장 짧은 고유 조각(한 문장 이내). 표는 그 행 전체.
3. 같은 수가 여러 번 나오면 나올 때마다 한 줄(같은 `calc` 를 써도 된다).
4. `calc` 는 파이썬과 R에 **둘 다** 구현한다. R은 파이썬 코드를 옮기지 말고 R의 함수(`lm` · `t.test` · `cor` …)로 따로 짠다.
5. 대조가 실패하면 책을 고칠지 계산을 고칠지는 원인을 찾아 정한다. 대조표의 `printed` 를 계산값에 맞춰 바꾸지 않는다(책과 대조표가 함께 틀린 채 통과한다).

## 결과

`python verify.py --out report.md` 가 보고서를 낸다. 실패가 하나라도 있으면 종료 코드가 1이다.
